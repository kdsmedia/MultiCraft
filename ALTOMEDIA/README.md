## Cepat Mulai

1. Buka **`BUILD_INFO.txt`** — ringkasan build terbaru, checksum, identitas app.
2. Untuk upload: ikuti **`docs/UPLOAD_GUIDE.txt`** langkah-demi-langkah.
3. File yang diupload ke Play Console: **`aab/MultiCraft-...-release.aab`**.
4. Isi store listing dari **`docs/STORE_LISTING.txt`**.
5. Host **`docs/PRIVACY_POLICY.txt`** ke URL publik (lihat UPLOAD_GUIDE LANGKAH 4).
